# OECRecorder

*Optoelectronic Compass Recorder (регистратор оптико-электронного компаса)*

## Зачем это нужно?
OECRecorder предназначен для периодической регистрации отладочных данных с оптико-электронного компаса для анализа поведения алгоритма в реальных условиях применения.

## Глоссарий 
ОЭК - оптико-электронный компас

---

**🗓️ Планируемый функционал:**
1. Подписка на топики сообщений ROS2 для извлечения в конкретный момент времени:
    - необработанного (raw) кадра
    - кадра, обработанного фильтром шумов и алгоритмом сегментации
    - конечного кадра, где было произведено определение угла по сегментированной картине.
    - информации об определённом угле азимута
2. Синхронизация с метеосервисом Open-Meteo для запроса прогноза погоды и связывания этого прогноза с полученными от ОЭК данных.
3. Получение угла азимута из другого источника для сравнения (к примеру, специально настроенный *(позже будет описано, как это будет устроено)* смартфон под управлением ОС Android. Если такого не обнаружится, регистрацию можно будет продолжать без него, в сравнительном показателе будет выведено "NaN".
4. Изолирование полученной картины в п.1, п.2 и п.3 в отдельную директорию по шаблону 
```
/ДД_ММ_ГГГГ/ЧЧ_ММ_СС/
```
5. Просмотр уже зарегистрированные данные, не прерывая сам процесс регистрации. Также возможность настроить периодичность регистрации данных.

## 🛠️ Необходимое ПО для разработчика (devkit)
- Ubuntu 22.04 LTS
- Командная оболочка bash версии 5.1.16
- QT Creator версии 18.0.2
- CMake версии 3.16 и выше
- GCC версии 11.4.0
- полный пакет разработчика ROS2 Humble

## 📚 Необходимые библиотеки
- OpenCV

*идут в пакете разработчика ROS2 Humble:*
- rclcpp - основная библиотека ROS2 для С++
- cv_bridge - библиотека-мост для перевода графической информации с языка OpenCV на ROS2

## ⚠️ ВАЖНО ЗНАТЬ!
Чтобы сборка проекта прошла успешно, системе сборки нужно быть запущенной в окружении ROS2.

Для этого необходимо выполнить в терминале, встроенном в Ubuntu:
```
source /opt/ros/humble/setup.bash
```

И из этого же терминала выполнить
```
qtcreator &
```
*(примечание - если установка Qt Creator производилась иным способом, например через официальный установщик с сайта разработчиков, то вместо "qtcreator" необходимо указать полный путь с файлом или перейти в директорию с файлом qtcreator и выполнить команду выше.*

*Для рекомендуемой версии IDE путь к файлу будет иметь вид <некий_каталог>/qtcreator-18.0.2/bin)*
